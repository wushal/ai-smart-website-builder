# 我用 AI 做了个 Skill，一句话就能生成生产级企业官网

> 还在用 AI 生成千篇一律的紫蓝渐变网站？这个开源 Skill 让 AI 懂设计、懂行业、懂反 AI 味道。

## 前言

你有没有这样的体验：用 AI 生成网站，乍一看不错，仔细看——紫蓝渐变、居中 Hero、三列卡片、fadeInUp 动画……每个网站长得都一样，一眼就能看出"这是 AI 写的"。

我深受其扰，于是做了一个 TRAE Skill：**AI Native Website Architect**。它能在 TRAE IDE 里通过一句话描述，生成一套完整的、生产级别的企业官网代码——而且**主动避免 AI 生成风格**。

GitHub 地址：https://github.com/wushal/ai-smart-website-builder

## 一、它能做什么？

输入一句话：

```
帮我生成一个高端牙科诊所网站，要有预约功能
```

AI 会自动完成：

1. **需求分析**：识别行业（医疗）、业务目标（预约转化）、目标用户
2. **设计系统选择**：匹配医疗行业专属色彩、字体、动效规范
3. **组件选择**：选择 TrustBadge、DoctorCard、ServiceCard 等医疗行业组件
4. **布局生成**：使用医疗行业专属布局（非通用模板）
5. **代码生成**：完整的 React + TypeScript + TailwindCSS 项目
6. **多语言填充**：自动生成中/英/日/韩四种语言文案
7. **主题适配**：深浅双主题，CSS 变量驱动

最终产出一个可以直接 `npm install && npm run dev` 运行的完整项目。

## 二、核心特性

### 🎯 一句话生成完整项目

不是生成一个页面，而是生成一整套工程：
- React 18 + TypeScript
- Vite 构建
- TailwindCSS 样式
- Framer Motion 动效
- Zustand 状态管理
- react-i18next 多语言
- 完整组件、页面、配置文件

### 🏭 四大行业差异化设计

这是这个 Skill 最核心的部分——**不同行业生成完全不同的视觉风格**：

| 行业 | 视觉风格 | 色彩系统 | 动效特点 |
|------|---------|---------|---------|
| **科技** | 暗色极简、Linear 风格 | 深色背景 + 品牌色点缀 | 克制、科技感 |
| **医疗** | 明亮专业、信任感 | 白色/浅蓝 + 医疗蓝 | 温和、稳重 |
| **电商** | 高冲击力、转化导向 | 品牌主色 + 高对比 | 动感、紧迫感 |
| **跨境** | 生活方式、品牌故事 | 柔和色系 + 全球视野 | 流畅、叙事感 |

每个行业都有：
- 专属组件清单（医疗有 DoctorCard，科技有 CodeBlock，电商有 ProductCard）
- 专属色彩系统（禁止跨行业混用）
- 专属布局规则
- 专属动效强度

### 🧠 反 AI 风格检测机制

这是我最得意的设计。我建立了一套完整的检测规则：

**禁止使用的 "AI 万能色"：**
```
#8B5CF6（霓虹紫）— AI 生成器最常用的颜色
#06B6D4（霓虹青）— 过度使用
#667eea（紫蓝渐变）— 过度使用
#764ba2（深紫）— 过度使用
```

**禁止的 AI 模式：**
- 全屏紫蓝渐变背景
- 所有卡片都用相同的 hover 效果
- 每个元素都有 fadeInUp 入场动画
- 居中 Hero + 三列 Features 的固定布局
- "赋能"、"革命"、"智能"等空泛文案

**强制规则：**
- 每页最多 1-2 个渐变区域
- 卡片样式必须根据类型变化
- 动画缓动函数必须多样化
- 文案必须具体、有数据支撑

### 🌍 多语言 + 双主题

- **4 种语言**：中文、English、日本語、한국어
- **双主题**：深色/浅色模式，CSS 变量驱动，丝滑切换
- **状态持久化**：语言和主题偏好存储在 localStorage
- **统一状态管理**：Zustand 统一管理 theme/lang/chat 状态

## 三、技术实现思路

### Skill 架构

```
SKILL.md（主调度文件）
  ├── generators/（生成器）
  │   ├── analyze-request.md    → 需求分析
  │   ├── select-component.md   → 组件选择
  │   └── generate-code.md      → 代码生成
  ├── design-system/（设计系统）
  │   ├── industries/           → 行业专属设计
  │   │   ├── technology/
  │   │   ├── medical/
  │   │   ├── ecommerce/
  │   │   └── cross-border/
  │   └── quality-check/        → 质量检测
  │       └── ai-style-check.md → AI 风格检测
  └── react-starter/（项目模板）
      └── src/config/
          ├── i18n.ts           → 多语言配置
          ├── store.ts          → 状态管理
          └── themes.css        → 主题变量
```

### 反 AI 味道的核心策略

**1. 色彩检测**

在生成代码前，Skill 会检查色彩方案，如果检测到 AI 万能色组合，会强制替换为行业专属色：

```css
/* ❌ AI 默认色 — 被禁止 */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* ✅ 科技行业 — 深色 + 品牌色点缀 */
background: #0A0A0F;
color: #5E6AD2;
```

**2. 组件差异化**

核心组件（Button、Card）内置 `industry` 属性，根据行业自动调整样式：

- 科技：深色背景、矩形圆角
- 医疗：浅色背景、大圆角、禁用 hover 动画（保持专业）
- 电商：鲜艳色彩、强 hover 效果（促进转化）

**3. 布局多样性**

每个行业有独立的布局规则文件，禁止使用通用模板。例如医疗行业必须包含预约组件，电商行业必须包含产品网格。

## 五、如何使用

### 安装

```bash
git clone https://github.com/wushal/ai-smart-website-builder.git
```

### 在 TRAE 中使用

1. 在 TRAE 对话中引用 SKILL.md
2. 用自然语言描述你的需求：

```
帮我生成一个AI客服SaaS官网
```

```
需要一个高端牙科诊所网站，要有预约功能
```

```
我想要一个有机护肤品电商网站，风格简约清新
```

3. AI 自动生成完整项目，`npm install && npm run dev` 即可运行
