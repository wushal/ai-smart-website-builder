# UI Quality Check


Purpose:

Ensure generated websites meet professional frontend design standards.


---

## Layout


Check:


- Clear visual hierarchy
- Balanced whitespace
- Proper content density
- Consistent grid system


Avoid:


- Crowded sections
- Random alignment
- Excessive empty space


---

## Typography


Check:


- Clear heading hierarchy
- Readable body text
- Consistent font sizes


Avoid:


- Oversized titles everywhere
- Too many font styles


---

## Components


Check:


- Reusable components
- Consistent button styles
- Consistent border radius
- Consistent spacing


Avoid:


- Every section using different styles


---

## Responsive Design


Check:


- Mobile layout
- Tablet adaptation
- Image scaling
- Navigation behavior


---

## Interaction


Check:


- Hover states
- Loading states
- Smooth transitions
- Accessibility


---

## Professional Standard


The final website should look like:

A real production website.

Not:

A generated prototype.
