# AI 风格检测规则

> 本规则文档旨在检测并避免 AI 生成网站中常见的"AI味道"特征，确保生成的网站具有真实、专业、独特的品牌气质。

---

## 一、什么是"AI味道"

"AI味道"指的是 AI 生成内容中普遍存在的模式化、同质化特征，这些特征会让用户一眼就能识别出这是 AI 生成的内容，而非专业设计师的作品。

### 常见的 AI 风格特征

| 特征类别 | 具体表现 | 问题描述 |
|---------|---------|---------|
| **色彩** | 紫-蓝-青渐变无处不在 | 缺乏品牌个性，视觉单调 |
| **卡片** | 统一的 3xl 圆角 + hover 上移 | 千篇一律，缺乏差异化 |
| **动效** | 所有元素都有 fadeInUp + scale | 动效过度，没有重点 |
| **布局** | 居中 Hero + 三列 Features + 定价卡 | 布局模板化，缺乏创意 |
| **文案** | 空洞的营销话术 | 缺乏真实感和可信度 |
| **阴影** | 统一的软阴影 | 层次感不足 |

## 二、色彩检测规则

### 2.1 禁止过度使用渐变

**检测标准**：
- 一个页面中使用超过 3 个不同的渐变区域 → AI 风格倾向高
- 渐变角度集中在 135° → AI 风格倾向高
- 渐变色集中在紫色-蓝色-青色区域 → AI 风格倾向高

**优化方案**：
- 每个页面最多使用 1-2 个渐变区域
- 渐变角度应根据行业调整（科技：45°-135°，医疗：0°-45°，电商：任意）
- 使用行业专属色彩系统，避免通用渐变

### 2.2 禁止色彩滥用

**检测标准**：
- 页面中出现超过 5 种饱和度 > 60% 的颜色 → AI 风格倾向高
- 文字使用渐变效果 → AI 风格倾向高
- 按钮使用渐变背景 → AI 风格倾向高（除电商促销场景外）

**优化方案**：
- 严格遵循 60-30-10 色彩比例原则
- 科技行业：暗色背景 + 单一品牌色强调
- 医疗行业：浅色背景 + 柔和色调
- 电商行业：产品色彩为主，品牌色为辅

### 2.3 禁止使用"AI 万能色"

**AI 万能色清单**（应避免）：
- `#8B5CF6`（霓虹紫）- 过度使用
- `#06B6D4`（霓虹青）- 过度使用
- `#667eea`（紫蓝）- 过度使用
- `#764ba2`（深紫）- 过度使用

**替代方案**：
- 根据行业选择品牌色：
  - 科技：`#006bff`（Vercel 蓝）、`#10A37F`（OpenAI 绿）
  - 医疗：`#3B82F6`（医疗蓝）、`#10B981`（健康绿）
  - 电商：`#FF6B6B`（活力红）、`#F7931E`（温暖橙）
  - 跨境：`#2563EB`（信任蓝）、`#EC4899`（时尚粉）

## 三、组件检测规则

### 3.1 卡片设计检测

**检测标准**：
- 所有卡片使用相同的圆角（3xl）→ AI 风格倾向高
- 所有卡片使用相同的 hover 效果（上移 8px）→ AI 风格倾向高
- 卡片阴影使用统一的 `shadow-sm` → AI 风格倾向高

**优化方案**：
- 根据卡片类型使用不同圆角：
  - 信息卡片：`rounded-xl`（12px）
  - 内容卡片：`rounded-2xl`（16px）
  - 产品卡片：`rounded-3xl`（24px）
- 根据卡片重要性使用不同的 hover 效果：
  - 普通卡片：无 hover 效果或轻微缩放（scale 1.02）
  - 重要卡片：上移 + 阴影增强
  - 产品卡片：缩放 + 阴影增强
- 使用多层次阴影：
  - 悬浮卡片：`shadow-xl`
  - 内容卡片：`shadow-md`
  - 背景卡片：`shadow-sm`

### 3.2 按钮设计检测

**检测标准**：
- 所有按钮使用相同的样式 → AI 风格倾向高
- 按钮使用 `whileHover={{ scale: 1.05 }}` → AI 风格倾向高
- 按钮使用渐变背景 → AI 风格倾向高

**优化方案**：
- 建立按钮层级系统：
  - 主 CTA：实心品牌色，悬停时阴影增强
  - 次 CTA：描边按钮，悬停时背景填充
  - 辅助按钮：文字按钮，悬停时下划线
- 根据行业调整按钮风格：
  - 科技：简洁方正（rounded-lg）
  - 医疗：圆润柔和（rounded-full）
  - 电商：醒目有力（rounded-xl）
- 按钮动效应克制：
  - 主 CTA：轻微缩放 + 阴影
  - 其他按钮：颜色变化即可

### 3.3 布局模式检测

**检测标准**：
- 页面结构为：Navbar → Hero → Features(3列) → Workflow → Pricing → FAQ → Footer → AI 风格倾向高
- Hero 区域始终居中布局 → AI 风格倾向高
- Features 区域始终使用 3 列网格 → AI 风格倾向高

**优化方案**：
- 根据行业调整页面结构：
  - 科技：Hero → Social Proof → Features → Workflow → Product Demo → Pricing → FAQ
  - 医疗：Hero → Trust Signals → Services → Doctors → Testimonials → Contact → FAQ
  - 电商：Hero → Product Showcase → Benefits → Reviews → Best Sellers → CTA → Footer
  - 跨境：Hero → Brand Story → Product Gallery → Lifestyle → Reviews → Shipping → Newsletter
- 根据内容调整布局：
  - 科技：居中布局 + 深色背景
  - 医疗：左右分屏 + 浅色背景
  - 电商：产品展示 + 图片主导
  - 跨境：全屏视觉 + 故事叙述

## 四、动效检测规则

### 4.1 动效过度检测

**检测标准**：
- 页面中超过 5 个元素有入场动画 → AI 风格倾向高
- 背景同时有渐变动画 + 粒子效果 → AI 风格倾向高
- 卡片有 hover 动画 + 入场动画 + 滚动动画 → AI 风格倾向高

**优化方案**：
- 遵循"一动为主，多动为辅"原则：
  - 首屏：标题入场 + CTA 入场 + 产品视觉入场（3 个）
  - 其他区域：最多 1 个主要动效
- 背景动效应克制：
  - 科技：渐变缓慢流动（15s+）
  - 医疗：无背景动效或极淡渐变
  - 电商：产品图片为主，无背景动效
- 滚动动效应选择性使用：
  - 重要信息：滚动渐入
  - 次要信息：直接显示

### 4.2 动效模式化检测

**检测标准**：
- 所有元素使用相同的入场动画（fadeInUp）→ AI 风格倾向高
- hover 效果统一使用 scale(1.05) → AI 风格倾向高
- 浮动卡片使用统一的 float 动画 → AI 风格倾向高

**优化方案**：
- 动效多样化：
  - 标题：文字逐字显现（TextReveal）
  - 描述：淡入（FadeIn）
  - CTA：缩放 + 阴影（Scale + Shadow）
  - 产品：从下方滑入 + 缩放（SlideUp + Scale）
- 根据行业调整动效强度：
  - 科技：动效较多，层次丰富
  - 医疗：动效较少，温和克制
  - 电商：动效集中在产品区域
  - 跨境：动效集中在视觉区域

## 五、文案检测规则

### 5.1 空洞营销话术检测

**检测标准**：
- 使用"革命性"、"颠覆性"、"赋能"、"智能"等词汇 → AI 风格倾向高
- 描述性文字超过 3 行 → AI 风格倾向高
- 缺少具体数据和实例 → AI 风格倾向高

**优化方案**：
- 使用具体、真实的语言：
  - 避免："赋能企业数字化转型"
  - 推荐："帮助企业将运营效率提升 30%"
- 文案简洁有力：
  - Hero 标题：≤ 12 词（英文）/ ≤ 20 字（中文）
  - 描述文字：1-2 句话
- 加入真实数据：
  - 用户数量
  - 增长指标
  - 客户案例

### 5.2 缺乏品牌个性检测

**检测标准**：
- 文案风格中性，没有品牌特色 → AI 风格倾向高
- 缺少情感化表达 → AI 风格倾向高
- 语言过于正式，缺乏亲和力 → AI 风格倾向高

**优化方案**：
- 根据品牌调性调整文案风格：
  - 科技：专业、简洁、数据驱动
  - 医疗：温暖、关怀、专业可靠
  - 电商：活力、热情、促销导向
  - 跨境：高端、品质、生活方式

## 六、行业专属检测规则

### 6.1 科技行业

**禁止特征**：
- 使用紫色-蓝色渐变作为主背景
- 过度使用粒子效果
- 所有卡片悬停上移
- 文案空洞（如"AI 驱动的智能平台"）

**推荐特征**：
- 深色背景 + 单一品牌色强调
- 产品 Demo 作为视觉焦点
- 数据指标突出显示
- 简洁有力的技术文案

### 6.2 医疗行业

**禁止特征**：
- 使用深色背景
- 过度使用动画效果
- 使用紫色、粉色等非医疗色彩
- 卡片设计过于花哨

**推荐特征**：
- 浅色背景 + 蓝色/绿色主色调
- 医生照片和资质展示
- 患者评价和案例
- 清晰的服务流程

### 6.3 电商行业

**禁止特征**：
- 使用深色背景
- 产品图片使用低质量占位图
- 价格显示不突出
- CTA 按钮不醒目

**推荐特征**：
- 产品图片为主导
- 价格和折扣信息突出
- 多尺寸产品展示
- 清晰的购物引导

### 6.4 跨境行业

**禁止特征**：
- 使用单一纯色背景
- 产品图片缺乏生活场景
- 缺少国际化元素
- 品牌故事不完整

**推荐特征**：
- 全屏视觉 + 生活场景
- 品牌故事叙述
- 多语言标识
- 全球配送信息

## 七、检测清单

### 7.1 色彩检测
- [ ] 页面中使用的渐变色区域 ≤ 2 个
- [ ] 主品牌色符合行业规范
- [ ] 没有使用 AI 万能色（#8B5CF6、#06B6D4、#667eea）
- [ ] 色彩比例符合 60-30-10 原则

### 7.2 组件检测
- [ ] 卡片圆角根据类型有所不同
- [ ] 卡片 hover 效果根据重要性有所不同
- [ ] 按钮有明确的层级区分
- [ ] 按钮样式符合行业特色

### 7.3 布局检测
- [ ] 页面结构符合行业规范
- [ ] Hero 布局类型符合行业特征
- [ ] Features 区域不是单纯的 3 列网格
- [ ] 各区域之间有视觉变化

### 7.4 动效检测
- [ ] 入场动画元素 ≤ 3 个/区域
- [ ] 背景动效不干扰内容阅读
- [ ] 动效类型多样化（不是全部使用 fadeInUp）
- [ ] 移动端关闭不必要的动效

### 7.5 文案检测
- [ ] Hero 标题 ≤ 20 字（中文）
- [ ] 描述文字 ≤ 2 句话
- [ ] 使用具体数据而非空洞词汇
- [ ] 文案风格符合品牌调性

## 八、反 AI 风格设计原则

### 8.1 克制原则
- 不是所有元素都需要动画
- 不是所有卡片都需要悬停效果
- 不是所有背景都需要渐变

### 8.2 真实原则
- 使用真实产品截图而非占位图
- 使用真实数据而非虚构数字
- 使用真实客户评价而非模板化内容

### 8.3 差异化原则
- 每个行业有独特的视觉语言
- 每个品牌有独特的设计风格
- 每个页面有独特的布局方式

### 8.4 功能原则
- 设计服务于功能，而非炫技
- 动效服务于理解，而非装饰
- 色彩服务于品牌，而非潮流

## 九、参考案例

### 优秀案例（非 AI 风格）
| 品牌 | 行业 | 设计亮点 |
|------|------|---------|
| Linear | 科技 | 极简暗色、单一品牌色、克制动效 |
| Ro.co | 医疗 | 柔和色调、产品实拍、清晰信息层级 |
| Stripe | 金融科技 | 白色基底、Mesh Gradient、数据可视化 |
| Apple | 消费电子 | 大量留白、产品摄影、极简文字 |

### 避免案例（AI 风格）
- 所有元素都有动画的网站
- 紫色-蓝色渐变背景的网站
- 统一 3xl 圆角卡片的网站
- 文案空洞无物的网站
