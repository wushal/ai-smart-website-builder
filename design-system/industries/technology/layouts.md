# Technology Website Layout Rules


## Hero


Recommended:


Centered hero.


Include:


- Large headline
- Product description
- CTA
- Animated background

1. Hero

# Visual Style


Use:


- Full screen sections

- Motion effects


Avoid:


- Traditional enterprise layouts
