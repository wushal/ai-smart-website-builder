# Ecommerce Industry Layout Rules

> 电商行业官网布局规范：产品主导、转化驱动、购物体验优先

---

## 一、核心设计原则

### 1.1 电商设计价值观

| 原则 | 说明 | 体现方式 |
|------|------|---------|
| **产品优先** | 用户来购物，产品图片是核心视觉元素 | 大图展示、多角度视图、视频演示 |
| **转化驱动** | 每一个设计决策都服务于购买转化 | 醒目的 CTA、清晰的价格、促销信息 |
| **信任建立** | 消除购物顾虑，建立购买信心 | 评价体系、安全支付、退换货政策 |
| **购物便捷** | 降低购物流程复杂度 | 快速导航、精准搜索、流畅结算 |

### 1.2 视觉风格指南

**色彩**：
- 主色调：根据产品类型选择（时尚：活力橙/粉，电子产品：科技蓝/灰）
- 辅助色：强调色用于 CTA 和促销标签
- 背景：纯白或浅灰，让产品色彩脱颖而出
- 价格色：红色用于折扣价，黑色用于原价

**排版**：
- 标题：醒目有力，字重较重（700-800）
- 价格：突出显示，字号较大
- 描述：简洁明了，突出卖点

**动效**：
- 产品图片：放大预览、360° 旋转
- CTA：悬停状态变化、点击反馈
- 页面：平滑过渡，无干扰性动画

## 二、布局规范

### 2.1 Hero 布局

**推荐类型**：Split Hero（左右分屏）或 Product Showcase（产品展示）

**Split Hero**：
- 左侧：促销信息 + CTA
- 右侧：主打产品大图
- 比例：45:55 或 50:50

**Product Showcase Hero**：
- 全屏产品展示
- 简洁的促销文案
- 浮动价格标签

**设计要点**：
- 产品图片占据 50% 以上视觉空间
- 促销信息清晰醒目
- CTA 按钮突出

### 2.2 Product Showcase（产品展示区）

**布局方式**：
- 网格布局：2-4 列，根据产品数量调整
- 卡片式展示：每个产品独立卡片
- 瀑布流：适合产品数量较多的场景

**卡片内容**：
- 产品图片（高质量）
- 产品名称（简洁）
- 价格（原价 + 折扣价）
- 评分星级
- 销量/库存信息

**交互**：
- 悬停：图片放大、显示快速加入购物车按钮
- 点击：进入产品详情页

### 2.3 Benefits（优势区）

**布局方式**：
- 水平排列的图标 + 文字
- 2-4 个核心优势

**内容**：
- 免费配送
- 7 天无理由退换
- 安全支付
- 正品保证

**设计要点**：
- 图标简洁统一
- 文字简短有力
- 与产品区形成视觉对比

### 2.4 Reviews（评价区）

**布局方式**：
- 横向滚动卡片
- 居中展示 3-5 条评价

**卡片内容**：
- 用户头像
- 评分星级
- 评价内容
- 用户姓名
- 购买产品

**设计要点**：
- 真实评价更有说服力
- 包含带图评价
- 显示评价总数

### 2.5 Best Sellers（畅销区）

**布局方式**：
- 横向滚动产品卡片
- 突出"热销"标签

**设计要点**：
- 明显的热销标识
- 销量数据展示
- 紧迫感营造（如"仅剩 XX 件"）

### 2.6 CTA Banner（促销横幅）

**布局方式**：
- 全屏宽度横幅
- 醒目的促销信息
- 居中 CTA 按钮

**设计要点**：
- 限时优惠信息
- 清晰的折扣力度
- 紧迫感文案（"限时"、"仅剩"）

## 三、页面结构推荐

### 3.1 首页结构

```
Navbar（带搜索框 + 购物车）
    ↓
Hero（产品大图 + 促销信息 + CTA）
    ↓
Product Showcase（热门产品，3-4 列）
    ↓
Benefits（4 个购物保障）
    ↓
Best Sellers（热销产品，横向滚动）
    ↓
Reviews（用户评价）
    ↓
CTA Banner（促销活动）
    ↓
Footer（导航 + 联系方式）
```

### 3.2 产品详情页结构

```
Navbar
    ↓
Product Gallery（主图 + 缩略图）
    ↓
Product Info（名称 + 价格 + 规格 + 购买按钮）
    ↓
Product Description（详细描述 + 规格参数）
    ↓
Related Products（相关推荐）
    ↓
Customer Reviews（用户评价）
    ↓
Footer
```

## 四、禁止使用的布局模式

### 4.1 科技风格布局
- [ ] 居中 Hero 布局（电商应产品主导）
- [ ] 深色背景（产品图片需要浅色背景衬托）
- [ ] 粒子背景效果
- [ ] 浮动信息卡片

### 4.2 医疗风格布局
- [ ] 医生团队展示
- [ ] 信任徽章过多
- [ ] 服务流程冗长

### 4.3 通用限制
- 禁止使用渐变背景作为产品展示区背景
- 禁止使用过度动画干扰购物体验
- 禁止价格信息不清晰
- 禁止 CTA 按钮不醒目

## 五、真实案例参考

### 5.1 优秀电商网站特征
| 特征 | 说明 | 示例 |
|------|------|------|
| **高质量图片** | 产品图片清晰、多角度、场景化 | 白底图 + 场景图 |
| **价格透明** | 原价、折扣价、优惠信息清晰 | 红色折扣价 + 删除线原价 |
| **评价体系** | 用户评价真实可信 | 星级评分 + 文字评价 + 图片 |
| **促销标签** | 醒目但不干扰的促销标识 | "热销"、"限时优惠"、"新品" |
| **购物车状态** | 实时显示购物车数量 | Navbar 购物车图标带数字 |

### 5.2 设计灵感来源
- **Apple**：产品摄影极致、留白艺术
- **Nike**：运动场景、品牌故事、社区感
- **Allbirds**：环保理念、简洁设计、舒适感
- **Glossier**：极简包装、用户社区、真实照片
