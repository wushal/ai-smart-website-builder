# Medical Website Layout Rules


## Hero Layout


Recommended:


Two-column layout.


Left:


- Professional headline
- Medical description
- CTA


Right:


- Doctor image
- Hospital environment
- Medical illustration



Avoid:


Centered giant hero title.



---


# Homepage Structure


Recommended:


1. Hero


2. Medical Expertise


3. Treatment Services


4. Doctors Team


5. Clinical Advantages


6. Patient Stories


7. Contact


8. Footer



---


# Section Style


Use:


- Large whitespace
- Clear hierarchy
- Calm rhythm


Avoid:


- Dense cards
- Excessive decoration
