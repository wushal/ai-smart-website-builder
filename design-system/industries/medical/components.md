# Medical Industry Component Rules

> 医疗行业官网组件规范：温暖、专业、可信赖

---

## 一、核心设计原则

### 1.1 医疗设计价值观

| 原则 | 说明 | 体现方式 |
|------|------|---------|
| **信任感** | 医疗是高风险决策，信任是第一要素 | 医生资质、认证标志、患者评价 |
| **温暖关怀** | 患者需要情感支持，而非冷冰冰的技术 | 柔和色调、关怀文案、人性照片 |
| **清晰易懂** | 医疗信息复杂，需降低理解门槛 | 简洁文字、可视化流程、清晰层级 |
| **专业可靠** | 体现医疗专业性和权威性 | 数据展示、专家团队、技术优势 |

### 1.2 视觉风格指南

**色彩**：
- 主色调：医疗蓝（#3B82F6）、健康绿（#10B981）
- 辅助色：温暖橙（#F7931E）用于强调
- 背景：纯白或极浅灰（#F8FAFC）
- 禁止：紫色、粉色等非医疗色彩

**排版**：
- 标题：亲切温暖，字重适中（600-700）
- 正文：清晰易读，行高宽松（1.6-1.8）
- 强调：使用品牌色突出关键信息

**动效**：
- 克制使用，避免干扰用户决策
- 入场动画：淡入为主，时长适中（0.4-0.6s）
- 交互反馈：柔和过渡，无夸张效果

## 二、专属组件规范

### 2.1 TrustBadge（信任徽章）

**用途**：展示医院资质、认证、荣誉

**设计规范**：
- 形状：圆角矩形（rounded-lg）
- 背景：白色或极浅蓝（#EFF6FF）
- 边框：1px 医疗蓝边框
- 图标：医疗相关图标（认证、盾牌、奖项）
- 内容：认证名称 + 颁发机构

**交互**：
- 悬停：轻微阴影增强（shadow-md）
- 无缩放或位移动画

**使用场景**：
- Hero 区域下方
- 服务介绍区域
- 页脚信任区

### 2.2 DoctorCard（医生卡片）

**用途**：展示医生团队信息

**设计规范**：
- 形状：圆角卡片（rounded-2xl）
- 头像：圆形（rounded-full），尺寸 80-100px
- 背景：白色，轻微阴影（shadow-sm）
- 信息层级：
  1. 医生姓名（突出显示）
  2. 职称/科室（次要）
  3. 专长领域（简要）
  4. 从业年限（辅助）

**交互**：
- 悬停：阴影增强（shadow-md），无位移
- 点击：跳转医生详情页

**使用场景**：
- 医生团队区域
- 科室介绍页面

### 2.3 ServiceCard（服务卡片）

**用途**：展示医疗服务项目

**设计规范**：
- 形状：圆角卡片（rounded-xl）
- 图标：医疗服务图标，圆形背景
- 标题：清晰的服务名称
- 描述：简要服务说明（1-2 行）
- 价格：可选，突出显示

**交互**：
- 悬停：边框颜色变化，无缩放
- 点击：查看服务详情或预约

**使用场景**：
- 服务项目区域
- 首页服务展示

### 2.4 TestimonialCard（患者评价卡片）

**用途**：展示患者真实评价

**设计规范**：
- 形状：圆角卡片（rounded-xl）
- 背景：白色或浅灰
- 头像：圆形，尺寸 48px
- 内容：
  - 评分星级（★★★★★）
  - 评价内容（2-3 行）
  - 患者姓名 + 治疗项目
- 引用符号：左上角装饰性引号

**交互**：
- 无悬停效果（评价内容不需要交互）
- 支持左右切换

**使用场景**：
- 患者评价区域
- 服务详情页

### 2.5 AppointmentButton（预约按钮）

**用途**：引导用户预约挂号

**设计规范**：
- 样式：实心品牌色按钮
- 颜色：医疗蓝（#3B82F6）或健康绿（#10B981）
- 圆角：全圆角（rounded-full）
- 尺寸：较大（px-8 py-4）
- 图标：日历或时钟图标

**交互**：
- 悬停：颜色加深，阴影增强
- 点击：打开预约表单

**使用场景**：
- Hero 区域
- 服务卡片内
- 页面固定位置

## 三、组件层级体系

### 3.1 组件优先级

| 优先级 | 组件 | 说明 |
|--------|------|------|
| P0 | TrustBadge | 信任感是医疗网站的核心 |
| P0 | DoctorCard | 专家团队展示建立专业形象 |
| P1 | ServiceCard | 服务内容是用户核心需求 |
| P1 | TestimonialCard | 患者评价增强可信度 |
| P2 | AppointmentButton | 转化入口，需要突出 |
| P2 | FAQ | 解答常见疑问 |

### 3.2 组件组合规则

**首页推荐组合**：
```
Hero（医疗蓝背景 + 温暖标题）
    ↓
TrustBadge（3-4 个认证徽章）
    ↓
ServiceCard（4-6 个服务卡片，2-3 列）
    ↓
DoctorCard（3-4 个医生卡片，横向滚动）
    ↓
TestimonialCard（3 个评价卡片，居中展示）
    ↓
CTA（预约咨询）
    ↓
Footer
```

## 四、禁止使用的组件

### 4.1 科技风格组件
- [ ] ParticleBackground（粒子背景）
- [ ] FloatingCard（浮动卡片）
- [ ] GradientBackground（渐变背景）
- [ ] MagneticButton（磁性按钮）

### 4.2 电商风格组件
- [ ] ProductCard（产品卡片）
- [ ] PricingCard（定价卡片）
- [ ] CountdownTimer（倒计时）
- [ ] AddToCart（加入购物车）

### 4.3 通用风格限制
- 禁止所有卡片使用相同的悬停效果（hover 上移）
- 禁止使用深色背景（除非是特殊深色区块）
- 禁止使用渐变文字效果
- 禁止使用过度动画（粒子、浮动等）

## 五、真实案例参考

### 5.1 优秀医疗网站特征
| 特征 | 说明 | 示例 |
|------|------|------|
| **医生照片** | 真实、专业、亲切的照片 | 微笑的医生肖像 |
| **认证展示** | 清晰展示资质认证 | JCI、ISO、三甲医院标志 |
| **服务流程** | 可视化的就医流程 | 预约 → 诊断 → 治疗 → 随访 |
| **患者评价** | 真实的患者反馈 | 姓名、照片、评分、评语 |
| **价格透明** | 清晰的价格展示 | 挂号费、治疗费 |

### 5.2 设计灵感来源
- **Ro.co**：柔和色调、产品实拍、清晰信息层级
- **Zocdoc**：医生搜索、预约流程、用户评价
- **Mayo Clinic**：专业权威、内容丰富、可信赖
- **WebMD**：信息清晰、易于导航、医疗资源
